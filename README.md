# The Ants · 小小蚁国（蚁丘模拟 · 玩法 v4.0）

一款移动端蚁群策略游戏，**视觉为暗色岩洞、去饱和、带边缘暗角与土壤/岩层纹理的“压迫感”风格**（微光巢心、四周发黑、真实三节蚁形体、暗红威胁光晕），词汇为《The Ants: Underground Kingdom（小小蚁国）》（蚁丘/蚁后/特化蚁/神树），玩法仍为地下蚁国式：
**首页（新建蚁丘 / 查看存档）→ 选外观颜色创建“蚁丘” → 六边形主基地（建造 / 升级 / 进化 / 拆除）→ 关卡内用 5 支信息素队伍指挥蚁群。**

纯前端（HTML + Canvas + 原生 JS），无依赖，竖屏触控，可离线，可安装到主屏。

- 单文件：直接打开 `ant-kingdom.html`。
- 完整工程：`python3 -m http.server 8080`，手机浏览器打开 `http://<电脑IP>:8080/`。

## 二、首页与“家”

### 首页
- **新游戏**：选择蚁群颜色 → 创建一个新的“家”。
- **查看存档**：列出所有“家”，点击载入。

### 颜色
- 只影响**你的蚂蚁外观**，不影响地图、敌人、地块。

### 每个“家”独立存档
包含：食物、挖掘方块、蚁皇浆、已解锁进化、已通关关卡。

### 家的六边形巢穴
所有格子（土块、兵蚁孵化室、工蚁孵化室、加速方块、食物储存区、蚁后室）都是**六边形网格**。
- **蚁后室**：占 7 格；初始 7 只工蚁、35 食物、70 食物储存；无需升级。
- **挖掘**：点与通道相邻的泥土 → 消耗 1 个“挖掘方块”，挖出一格通道。
- **建造**：在底部选择建筑 → 点空位放置（需挨着已有区域），立即扣除食物。
- **升级**：关闭建造选择后点建筑 → 打开升级面板。

建筑与花费：

| 建筑 | 花费 | 效果 |
|---|---|---|
| 兵蚁孵化室 | 50 食物 | 持续产出兵蚁 |
| 工蚁孵化室 | 5 食物 | 持续产出工蚁 |
| 食物储存区 | 5 食物 | 储存上限 Lv1 10 / Lv2 30 / Lv3 50 |
| 加速方块 | 5 食物 | 蚂蚁踩上去移速 +10% / +20% / +30% |

### 升级点数（会被消耗）
- 点数由巢穴布局产出：**同类建筑相邻每对 +1 点**；**加速方块与其他建筑相邻每对 +1 点**；全巢累计。
- 升级**消耗点数**：升 2 级消耗 **6 点**，升 3 级消耗 **12 点**（从可用点数池中扣除）。
- 每次升级还需消耗与该建筑建造价相同的食物。
- 可用点数 = 全局累计点数 − 已消耗点数，显示在“家”顶部与升级面板；点数不够时升级按钮禁用。
- 六边形每格只有 6 个邻居，若按“局部邻格”计算，12 点不可达，因此采用全巢累计 + 消耗的池子机制。

### 进化
用蚁皇浆提升：生命 / 攻击 / 移动速度 / 搬运效率，或解锁“大型兵蚁”（兵蚁血量与攻击 +40%）。

### 资源循环
- 通关关卡获得：食物、挖掘方块、蚁皇浆。
- **食物先到“家”的地表，再由玩家点地表收取进仓库**（不直接入仓，工蚁也不自动搬）：离开关卡时把关卡内剩余食物放到家的地表；回家时顶部地表条显示“地表食物 X · 点地表收取”，**点地表**即收取进仓库（受仓库上限限制）。
- **拆除建筑**：长按建筑（或在家/关卡的建筑面板）点“拆除”，返还 **70%** 建造食物；返还的食物同样**落到地表**（家里→家地表；关卡里→地表食物堆，蚂蚁可拾取），不进仓库。
- 挖掘方块只限制“家”里能挖多少格；**关卡内挖掘不受此限制**。
- 同一个“家”可重复挑战所有关卡，进度持续。

### 通关后可继续游玩
- 达成胜利条件（第一关清空敌人 / 第二关建够孵化室）后**不结束**，提示“已通关·继续游玩”，可继续收集食物。
- 点左上角 **←** 回家结算（食物送到家的地表 + 奖励挖掘方块/蚁皇浆）；未通关撤离不结算。
- 关卡会持续补给食物（地面刷新食物堆、蜘蛛死亡掉落），保证第二关扩建够用。

## 三、关卡

顶部资源栏显示 **食物 / 工蚁 / 兵蚁（数量与上限）**。底部为《小小蚁国》式 **4 个主按钮**：
- **建筑**：子面板「食物仓库 / 加速方格 / 拆除 / 挖地道」，选中即进入建造或拆除模式；**挖地道**=派工蚁过去在格子上把进度挖满才变通道（非点击瞬挖，返 70% 拆除食物到地表）；
- **蚂蚁**：子面板「工蚁 / 兵蚁」建孵化方格（工蚁取卵→卵→幼虫→蛹→耗食物羽化，见下方孵化系统）；
- **信息素**：先选队伍 Ⅰ–Ⅴ，再点地图放信息素点（该队蚂蚁到点后**散开成一片**而非全挤中心；攻/搬开关与最大出动数在此）；
- **到地面**：切换 地下 ↔ 地表 视图（地表看蜘蛛 / 食物堆 / 出入口）。

### 第一次玩：4 步让蚂蚁动起来
1. 底部 **蚂蚁** → 选「工蚁」，点**蚁后旁边空地**建造孵化室。
2. 底部 **信息素** → 点 **Ⅰ** 选中队伍。
3. **点刚建的孵化室**，把它分配给队伍 Ⅰ（会有提示）。
4. 在地图上**点一下**放一个信息素点（该队蚂蚁会跟随）。再点新点，旧点消失、蚂蚁改道；长按信息素点可删除。

> 提示：选中队伍后，顶部会显示“队Ⅰ N只”；点孵化室可重新分配到当前队伍；双击队伍按钮会清空该队所有孵化室分配。

### 5 支信息素队伍 Ⅰ–Ⅴ
- 点队伍按钮选中。
- 选中后点**孵化室** → 把它分配给该队伍；同队可包含多个孵化室，产出的蚂蚁都响应本队信息素。
- 选中队伍后在地图**点击/拖拽**放**信息素点**；每队**只有一个信息素点**，放新的会顶掉旧的；本队蚂蚁优先前往该点。
- **长按信息素点**可删除它（蚂蚁随即在巢口附近待命）。
- **双击队伍按钮** 清空该队伍的孵化室分配。
- 每队两个独立开关：
  - **允许攻击**：开启时途中遇敌自动攻击；关闭时绕路/撤退。
  - **允许搬运**：开启时遇食物自动搬回；关闭时只按信息素移动、不拾取。
- 每队可设置**最大出动数量**，超出的蚂蚁留在孵化室附近待命。
- 食物储存区满时无法拾取食物；已携带食物的蚂蚁仍可送回，但满仓后不能再拾取。

### 场地规则
- 蚂蚁站在孵化室上移速 −20%。
- 加速方块提升踩在其上的蚂蚁移速。

### 挖掘与探查（照 地下蚁国）
- **敌人不会开局就出在面上**：它们**埋进泥土里**（面包虫/鼠妇/甲虫/蜘蛛等 + 泥土食物）。
- **玩家挖掘**：用「挖地道」派工蚁把前线泥土挖成通道，**挖到埋藏那一格，敌人/食物才钻出**。
- **玩家知道哪里危险**：前线泥土上有标记——**红色「！」=埋藏敌人**、**金色「食」=埋藏食物**、**虚线框=可挖前线**；点未挖的前线泥土可**探查**（提示里面有什么）。
- 第一关胜利=清光所有威胁（活跃敌人 + 仍埋土的敌人都要找到并击败）。

### 孵化系统（卵 → 白幼虫 → 黄蛹 → 羽化）
建造**孵化方格**（工蚁/兵蚁）后，它按生命周期孵化出蚂蚁：
1. **取卵**：空着的孵化方格，由**空闲工蚁**去蚁后处取卵；若蚁后没有卵、或没有空闲工蚁，则停滞（工蚁不足 → 卵无法及时搬入）。
2. **卵 → 白色幼虫 → 黄色蛹**：依次孵化（格上显示卵/幼虫/蛹）。
3. **耗食物羽化**：蛹→活跃蚂蚁需食物（**工蚁 2 / 兵蚁 5**，孵化方格等级越高越贵）；食物不够时**停在蛹阶段**，够了才羽化。
4. **自动入巢组**：新孵化的蚂蚁自动分配到该方格的队伍；工蚁负责巢穴工作，**兵蚁默认守在蚁后附近**。

关键规则：
- **人口上限 = 孵化方格数**（HUD 显示「活跃蚁 / 最大种群」，含活跃蚁与正在孵化的幼虫）。
- **一个方格绑定一只蚁**：活跃蚁死亡后，该方格**重新取卵并快速羽化补充**，然后变空等工蚁重搬。
- **孵化方格可升级**（最高 3 级），升级后孵出的蚁属性更强。
- **只有工蚁**能搬卵、建造、挖地道；兵蚁专司守卫/战斗。

### 第一章 · 第一关
- 胜利：击败所有敌人。
- 场景：完全地下，无出口。
- 敌人：甲虫、成年甲虫、鼠妇、面包虫。
- 面包虫死亡 +50 食物；鼠妇死亡留下尸体，可被分解 2 次，每次 +40 食物。

### 第一章 · 第二关
- 胜利：额外建成 **50 个兵蚁孵化室**和 **47 个工蚁孵化室**（蚁后初始 7 只工蚁不计入）。
- 场景：有出口，但你的蚂蚁不能离开；敌对蚂蚁可从出口进入。
- 敌人不再开局就在外面：蜘蛛/蛛丝蜘蛛/敌对蚂蚁都**埋进土里**，玩家挖掘才钻出；蛛丝洞穴只作地表食物巢（不自动秒杀）。
- 蛛丝蜘蛛不再一击秒杀（伤害有限、需击败）；蚁死后靠孵化方格快速补充。
- 敌对蚂蚁每 **120 秒**来袭一次，偷走 **10 只幼蚁**；没有幼蚁时攻击蚁后。
- 关卡开始时地面约有 500 食物。

## 四、文件结构

```
ant-kingdom/
├─ index.html            # 页面骨架
├─ style.css             # 界面样式

├─ sw.js                 # 离线缓存

├─ build-standalone.js   # 生成单文件版
├─ make-icon.js          # 生成图标
└─ serve.py              # 本地测试服务器
```

## 五、打包成原生 App

可用 Capacitor 把本目录包成 Android/iOS：

```bash
npm i -D @capacitor/cli
npx cap init "地下蚁国" com.example.antkingdom --web-dir=.
npm i @capacitor/android @capacitor/ios
npx cap add android
npx cap sync
npx cap open android
```

## 六、实现边界说明
- 这是按上述规格实现的**可玩版本**，不是商业原作的 1:1 复刻（原作为 3D、拥有大量物种与战役内容）。
- 升级点数因六边形邻接上限，采用“全巢累计、升级消耗”的实现（2 级耗 6 点、3 级耗 12 点 + 等同建造价的食物）。
- 关卡敌人 AI、蜘蛛洞穴与来袭路线为简化实现，核心规则（产蚁、队伍、开关、搬运上限、建造计数、奖励结算）均已落地。
